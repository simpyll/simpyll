# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities, credentials, or exploit details in public GitHub issues or pull requests.

Use [GitHub private vulnerability reporting](https://github.com/simpyll/simpyll/security/advisories/new) when available, or email **simpyll.com@gmail.com** if you cannot use GitHub. Include a concise description, affected URLs or components, and steps to reproduce; avoid sending real credentials or sensitive personal data.

The repository owner must enable **Private vulnerability reporting** under Settings → Code security and analysis for the GitHub link to accept reports. This repository file does not itself enable that setting.

Reports are reviewed on a best-effort basis; no response or resolution time is guaranteed.
