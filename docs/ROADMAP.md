current execution plan. Its October 27, 2026 audit revision has a versioned
[Simpyll v1 completion companion](roadmap/simpyll-v1-completion.md).

The finite stabilization queue is #184, #67, #133, #88 and #43. Optional work is

[issue dispositions](audits/simpyll-issue-disposition-2026-10.md) and
[confirmed GitHub changes and limits](audits/simpyll-github-reconciliation-2026-10.md).

After meaningful merges, update #89 and its companion together. Verify present
code and acceptance evidence before recommending or closing an issue. A closed
issue is not proof of release validation; an open issue can already contain a
merged implementation. Do not re-create completed foundations or make deferred
features prerequisites for moving to Cortex.
