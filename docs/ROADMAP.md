# Roadmap

[← README](../README.md)

The authoritative execution plan is [living roadmap issue #89](https://github.com/simpyll/simpyll/issues/89).
It records the audit date and main commit, distinguishes proposed work, open PRs,
merged implementations and production verification, and contains the next five
issues, execution phases and complete backlog assessment.

Use #89 for current priorities and dependencies. Individual issues retain their
requirements and acceptance criteria. This document intentionally does not copy
the feature list or execution order, so it cannot become a competing roadmap.

Revisit #89 after significant merges, demonstrated defects or publishing changes.
Completed foundations should be extended rather than queued for reimplementation;
deferred experiments are retained ideas, not a promise to ship.
