# Roadmap

[← README](../README.md)

Planned improvements are tracked as [GitHub issues](https://github.com/simpyll/simpyll/issues). This is a roadmap, not a claim that the features are already shipped.

## Core reading experience

Search, reading time and progress, article navigation, breadcrumbs, sticky table of contents, tags, categories and comments.

## Portfolio and interaction

Project case studies, interactive demos, command palette, bento homepage, theme controls, animations and technology showcase.

## Advanced exploration

Knowledge graph, activity heatmap, public metrics, interactive resume and optional terminal.

## Quality and publishing

Accessibility, performance, SEO, automated tests, RSS and content validation.
